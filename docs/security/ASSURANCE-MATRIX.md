# API Security Assurance Matrix

Status vocabulary: **PROVEN** means repository tests exercise the invariant;
**PARTIAL** means only a narrower seam is tested; **DEPLOYMENT** means the
production topology must supply the evidence; **OPEN** means implementation
work remains.

| ID | Asset / attacker | Attack | Invariant | Control + test | Release command | Status / residual dependency |
|---|---|---|---|---|---|---|
| AUTH-01 | External credential; stolen-key holder | Raw credential leakage | Reusable external secrets never cross the terminator | Carrier stripping, mTLS-backed compiled release fixture, capture/canary scan | `bash scripts/release-harness.sh` | PROVEN locally; production trace/packet scan remains deployment evidence |
| AUTH-02 | Auth parser; arbitrary client | Duplicate or ambiguous credential carriers | Multiple carriers fail closed and none reach adapters/backend | Extraction tests, sanitized forwarding tests, raw TCP duplicate/comma cases | `bash scripts/release-harness.sh` | PROVEN for exercised carriers; broader provider-specific carriers remain adapter work |
| AUTH-03 | Backend verifier; forged-assertion attacker | Wrong audience/issuer/KID, expiry, revision, or signature | Only a valid audience-bound assertion is accepted | `verify` conformance plus separate compiled assertion fixture | `go test ./verify ./cmd/gripline` | PROVEN |
| AUTH-04 | Internal assertion; bearer replay attacker | Reuse a valid JTI within its short TTL | Shared verifier instances accept each namespaced JTI once until expiry | Atomic `ReplayGuard`, PostgreSQL adapter, two-process race lab | `bash scripts/qualification/replay.sh` | PROVEN in the repository reference lab; operator-specific shared-store latency/availability remains deployment evidence |

| SUPPLY-01 | Build/dependencies; supply-chain attacker | Vulnerable dependency or unsafe code path | Static/vulnerability/provenance gates block unreviewed findings | Vet/staticcheck/govuln, pinned gosec workflow, SBOM/signatures/provenance | CI security workflow | PARTIAL until hosted workflow/artifact evidence is retained |

The matrix is intentionally conservative: a unit test is not substituted for a
raw-protocol or production-network qualification. The repository now ships a
reference production lab for HA, PITR, mTLS/network isolation, official SDKs,
HTTP/2, shared replay, and soak; operator-specific cloud/Kubernetes/PKI and
managed-database evidence remains a separate deployment layer.

Fuzz smoke is executable through `scripts/fuzz-smoke.sh` and covers the
assertion/key-set, policy, usage, ingress, pseudonym, endpoint-normalization,
and admin JSON parser seams. It is short PR coverage; scheduled runs use a
longer budget but are not a substitute for production load qualification.
